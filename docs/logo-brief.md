# Nexus — 软件 Logo 生成简介（发给 GPT/图像模型用）

## 一句话定位
Nexus 是一款运行于 Windows 的**本地 AI Agent 算力监控中心**：一台电脑上所有 AI 编程助手/Agent（ZCode、Codex、Claude Code、DeepSeek Harness、CodeBuddy、WorkBuddy、Qoder、Trae、Reasonix、OpenCode 等 12 个）的 Token 消耗、请求数、估算成本、会话明细，全部自动采集汇总到一个桌面看板。

## 核心气质关键词
- **本地优先**：所有数据只存本机（SQLite），不上云、无账号体系
- **枢纽/汇聚**：名字 Nexus 本义"网络节点/连接点"——多 Agent 数据汇于一处
- **监控仪表**：趋势曲线、环形占比、热力图、排行——冷静的数据密度感
- **暗色科技感**：主界面为暗色主题（#161616 底 + 蓝紫青系图表色），亮色为辅

## 视觉建议（供参考）
- 母题方向（任选或融合）：**节点/连接**（多线汇聚到一个中心点）、**仪表指针**、**脉冲波形**、字母 N 的几何重构
- 风格：扁平/微拟物均可，几何化、线条干净、有科技感但不过度科幻
- 配色：深色背景上需醒目；主色建议蓝紫青系（#3B82F6 / #7C5CFF / #14B8A6 任一），或与各厂商品牌色（蓝紫为主）形成区分的**单一强调色**
- 用途：应用图标（Windows 桌面/任务栏，圆角方形、可辨识度高）、顶栏 16px 小图标（需在极小尺寸下仍清晰）
- 交付：1024×1024 PNG（透明背景最好）+ 若有 SVG 矢量版更佳
